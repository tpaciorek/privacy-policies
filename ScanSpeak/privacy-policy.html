1. What ScanSpeak is

ScanSpeak is an Android app for scanning book pages, recognizing text (OCR), storing content locally on the device, and reading text aloud.

2. What data the app processes

The app may process the following data saved or used by the user:

  • images of scanned pages,
  • text recognized using OCR,
  • scan titles and organizational metadata,
  • language and reading speed settings,
  • saved resume position,
  • technical data required for system text-to-speech and notifications.

3. Where data is stored

Scan data, OCR text, preferences, and resume state are stored locally on the user's device within the app's storage. In the current release build, user data backup is disabled so that book content and reading history are not copied to system backup services.

4. When data leaves the device

By default, ScanSpeak works locally. The exception is the optional "Improve text" feature. When used, selected text may be sent to the external LanguageTool service to generate spelling and grammar suggestions.

Endpoint used by the app for this feature: https://api.languagetool.org/v2/check

If you do not use the text improvement feature, the app does not send scanned page content to this service.

5. Permissions and system features

  • Camera / document scanner — to scan pages.
  • Internet — for optional text improvement via LanguageTool.
  • Notifications — to control background reading.
  • Foreground service (media playback) — so text-to-speech can continue after the app is minimized.

6. Ads, analytics, and user accounts

In the reviewed production build of ScanSpeak:

  • it does not require creating an account,
  • it does not display ads,
  • it does not use analytics SDKs to track user behavior.

7. How to delete data

Users can delete saved scans directly in the app. Deleting a scan removes the related text and stored page files from the app's storage.

8. Sharing data with third parties

Data is not sold. Except for the optional use of LanguageTool described above for text improvement, the app does not share user content with external services during normal operation.
